# Brand assets

| File | Use |
|---|---|
| `logo.svg` | Mark alone (150×150): avatar, favicon, small sizes |
| `logo-wordmark-light.svg` | Mark + name for light backgrounds (README default) |
| `logo-wordmark-dark.svg` | Mark + name for dark backgrounds (README in dark mode) |
| `social-preview.svg` / `.png` | 1280×640 card for links. Upload the PNG in **Settings → General → Social preview** |

The mark: a backstage arch where one skill stands under the spotlight while the others wait in the wings.

## Type

The name is set in [DM Serif Display](https://fonts.google.com/specimen/DM+Serif+Display) (SIL Open Font License 1.1) and converted to outlines, so the SVGs render the same without the font installed. Edit the shapes, not text.
